# SkillsGuard

> Static security scanner for AI agent skill packages (SKILL.md + bundled scripts)

## What is SkillsGuard?

SkillsGuard audits AI agent skills for security threats before installation or execution. It scans SKILL.md files, shell scripts, Python/Ruby/PowerShell code, Dockerfiles, and bundled dependencies for:

- **Prompt injection** — Instructions that hijack agent behavior
- **Exfiltration** — Attempts to leak secrets, code, or environment data
- **Command injection** — Unsafe shell execution, eval, dynamic imports
- **Persistence** — Backdoors, cron jobs, autostart mechanisms
- **Privilege escalation** — Sudo abuse, SUID binaries, container escapes
- **Obfuscation** — Base64/hex blobs, character encoding tricks
- **Supply chain attacks** — Typosquatting packages, suspicious dependencies
- **Model-specific jailbreaks** — Exploits targeting Claude, GPT, Gemini, etc.

**100+ detection rules. Zero runtime dependencies. Runs local or via free cloud API.**

## Quick Start

### Option 1: Free Cloud API (no install)
```bash
curl -s --data-binary @SKILL.md \
  https://skillsguard.apiskillsguard.workers.dev/scan | jq .
```

### Option 2: Local CLI
```bash
git clone https://github.com/Teycir/SkillsGuard.git
cd SkillsGuard
npm install && npm run build && npm link
skillsguard /path/to/skill
```

### Option 3: MCP Server (Claude Desktop, Cline, etc.)
Add to MCP config:
```json
{
  "mcpServers": {
    "skillsguard": {
      "command": "node",
      "args": ["/path/to/SkillsGuard/dist/mcp.js"]
    }
  }
}
```

## Usage Patterns

### Scan a skill directory
```bash
skillsguard ./my-skill
```

### Scan a single SKILL.md
```bash
skillsguard SKILL.md
```

### Scan all skills in a folder
```bash
skillsguard ~/.codex/skills/
```

### JSON output (for CI/CD)
```bash
skillsguard --json ./skill | jq '.riskScore'
```

### Diff mode (scan only changed files)
```bash
skillsguard --mode diff --since main
```

### SARIF output (GitHub Code Scanning)
```bash
skillsguard --sarif ./skill > results.sarif
```

## Exit Codes

- `0` — Clean (no threats detected)
- `1` — Threats found
- `2` — Usage error

## When to Use SkillsGuard

**Before installing skills:**
- Scan community skills from GitHub/npm/registries
- Audit third-party SKILL.md files shared by users
- Review skills before adding to agent frameworks (Codex, LazyCodex, etc.)

**In CI/CD pipelines:**
- Block PRs that introduce malicious skills
- Run as pre-commit hook for skill repositories
- Integrate with GitHub Actions for automated security checks

**During development:**
- Watch mode (`skillsguard watch`) for live feedback
- MCP integration for on-demand scanning from Claude/Cline
- Hook into agent execution engines to intercept skill loads

## Detection Categories

| Category | Examples |
|----------|----------|
| **Prompt Injection** | "Ignore previous instructions", delimiter confusion, role hijacking |
| **Exfiltration** | `curl $SECRET`, DNS tunneling, GitHub API leaks |
| **Command Injection** | `eval()`, `exec()`, `subprocess.Popen(shell=True)`, `os.system()` |
| **Persistence** | Cron jobs, `.bashrc` modification, systemd services |
| **Privilege Escalation** | `sudo`, SUID binaries, Docker socket mounts |
| **Obfuscation** | Base64 blobs, hex encoding, URL-encoded payloads |
| **Supply Chain** | Typosquatting (`reqeusts`), suspicious package names |
| **Model Jailbreaks** | DAN prompts, token smuggling, refusal overrides |

## Configuration

Optional `skillsguard.config.json`:
```json
{
  "ignorePatterns": ["**/node_modules/**", "**/.git/**"],
  "severity": ["high", "critical"],
  "riskScoreThreshold": 30,
  "baselineFile": ".skillsguard-baseline.json"
}
```

## Architecture

1. **File discovery** — Recursively finds SKILL.md, JS, PY, SH, PS1, Dockerfile, Gemfile
2. **Rule engine** — Applies 100+ regex/AST patterns per file
3. **Decoder** — Extracts and recursively scans base64/hex/URL-encoded blobs
4. **Risk scoring** — Aggregates findings into 0-100 risk score
5. **Report** — ANSI, JSON, or SARIF output

Zero runtime dependencies. Runs on Node.js ≥18.3.
